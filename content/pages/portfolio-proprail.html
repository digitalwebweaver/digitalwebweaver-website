In short

PropRail is a cloud-based property management and accounting platform Digital Web Weaver built for a UK outsourced accounting firm. It runs many property entities on one tested double-entry ledger, follows RICS guidance, syncs with Sage 50, and controls access through 9 user roles, backed by more than 190 automated tests.

// the challenge

Many property entities, one set of books that has to balance

The firm manages the accounts of property owners and blocks across the UK. Each entity needs its own ledger, bank accounts and year-end, and every figure has to stand up to an accountant's review.

  • Entities kept in separate files

    Each client entity lived in its own spreadsheet or accounts file, so consolidated reporting meant manual copying.

  • Re-keying into Sage 50

    Property transactions were entered twice: once for management, once into Sage 50 for the accounts.

  • RICS expectations

    Service charge and client money handling has to follow RICS guidance, with a clear audit trail for every movement.

  • Too many people, one access level

    Partners, bookkeepers, property managers and clients needed different views of the same data, without seeing each other's.

// our approach

Ledger first, screens second

In accounting software, the numbers have to be right before anything else matters. We designed the double-entry ledger and its tests first, then built the property workflows on top of it.

  1. 01

    Discovery with the accountants

    Mapped the firm's chart of accounts, entity structure, month-end routine and Sage 50 export format.

  2. 02

    One ledger for every entity

    A single double-entry ledger where each posting belongs to an entity, so books stay separate but reports can combine them.

  3. 03

    Tests on every rule

    190+ automated tests cover postings, reversals, period locks and balances, and run on every release.

  4. 04

    Roles and workflows

    A 9-role access model, then the day-to-day screens for property managers, bookkeepers and clients.

What is PropRail?

PropRail is a cloud-based, multi-entity property management and accounting platform that Digital Web Weaver built for a UK outsourced accounting firm.

Does PropRail integrate with Sage 50?

Yes. Property transactions sync to Sage 50 automatically, so nothing is keyed in twice.

How does PropRail keep each property entity's books separate?

Every posting on the single double-entry ledger belongs to one entity. Each entity has its own accounts, periods and year-end, and reports can still combine entities.

How was the accounting logic tested?

More than 190 automated tests cover postings, reversals, period locks and balances, and they run on every release.

What technology is PropRail built on?

Laravel for the back end and API, Vue.js for the web app interface, and PostgreSQL as the transactional database.
