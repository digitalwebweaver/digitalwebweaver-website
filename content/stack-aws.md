## FAQ — AWS & Cloud FAQ
1. **AWS, GCP, or Azure — which do you recommend?** — AWS for most projects — widest managed service selection and mature ecosystem. GCP for ML-heavy workloads. Azure for Microsoft-integrated enterprises.
2. **Can you migrate our on-premise servers to AWS?** — Yes — lift-and-shift to EC2, re-platform to ECS/RDS, or re-architect to serverless. We scope the right approach per workload.
3. **Do you manage cloud costs?** — Yes — we set up Cost Explorer alerts, right-size instances monthly, and identify Reserved Instance opportunities.
4. **Can you set up Kubernetes on AWS?** — Yes — EKS with managed node groups, Helm charts, and autoscaler. Or ECS Fargate if K8s overhead isn't justified.
