2. **Can we add features later?** — Yes — we design MVPs with a clean architecture specifically so features can be added without major rewrites.
3. **Do you sign NDAs?** — Yes — we sign NDAs before any project discussions. Your idea is protected from the first conversation.
4. **What if we need mobile too?** — We can add a React Native app in weeks 6–8 reusing the same backend API, typically adding 2–3 weeks.
