## FAQ — Laravel Developer FAQ
1. **Livewire or Inertia.js?** — Livewire for server-centric apps with minimal JS. Inertia when you want React/Vue components with Laravel routing and no separate API.
2. **Can you deploy to Laravel Vapor?** — Yes — serverless Laravel on AWS Lambda with Vapor. We handle environment config, queues, and file storage for serverless deployments.
3. **Do you build Filament admin panels?** — Yes — Filament is our preferred Laravel admin solution. We build custom resources, widgets, and plugins.
4. **How long does a Laravel project take?** — A core API with auth and CRUD takes 2–3 weeks. Full-featured SaaS with billing and admin panel typically 2–4 months.
