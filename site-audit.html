SEO

Crawled all 73 sitemap URLs against both production and local source. The foundation is in genuinely good shape — the two real gaps are a broken subdomain and unclaimed rich-result opportunities.

Already solid — verified, not re-flagged
  • Sitemap: all 73 URLs return 200, no redirect drift, no orphaned pages
  • Every page has a self-referencing canonical; no accidental noindex anywhere
  • Organization + BreadcrumbList JSON-LD valid and rendering on every page
  • All 17 product pages already carry SoftwareApplication schema

High

www.digitalwebweaver.com has a broken TLS certificate

DNS is correctly configured, but https://www.digitalwebweaver.com fails the TLS handshake outright (SNI/cert mismatch), and the plain-HTTP version 308-redirects into that same broken connection. Any backlink, old bookmark, or directory listing using the "www." form sends both users and crawlers to a dead end. This is a Vercel domain-settings fix, not a code change.

High

Homepage LCP (2.7s) misses the 2.5s "good" threshold — and it's a text element

The LCP element is the hero paragraph, not an image — already in the initial HTML, but delayed 1.28 seconds by render blocking (TTFB is only 121ms). Main-thread work on this page hits 3.4s, the highest of any template tested, coinciding with the two largest JS chunks on the site. The homepage's typewriter-effect script is the likely gate: if it touches or rewrites the hero paragraph on mount, the text can't paint until the script initializes. Decoupling the two — let the hero text paint immediately regardless of when the typewriter script runs — is the single biggest lever available to fix this.

High

Location-page template runs 430ms of blocking time — 2× every other template

This is the lightest page tested by byte weight (369KB, 29 requests), yet has by far the worst Total Blocking Time. Since cost isn't proportional to bytes here, this points to CPU-bound JS execution — likely component hydration — specific to this template. Because location pages share one template, a fix here compounds across every one of them.

Where the effort should go first

Ordered by trust/ranking impact versus effort — not strictly by severity tag above.

  1. Fix the www subdomain's TLS cert in Vercel domain settings Ten-minute fix, currently sends any "www." backlink or bookmark to a dead connection.
  2. Reconcile the six conflicting numbers above sitewide Same pattern as the team-size fix already done — a single focused pass across a known list of pages.
  3. Address the portfolio case-study credibility problem Either substantiate 2–3 of the nine with real, dated, linkable case-study pages, or scope the claims down to what's verifiable.
  4. Decouple the homepage hero text from the typewriter script's init path Fixes the only Core Web Vitals "needs improvement" score on the site.
  5. Add FAQPage schema to the 8 location + 17 product pages The FAQ copy already exists — this is markup-only work with real rich-result upside.
  6. Everything else Title/description trimming, template differentiation on the clinic-vertical products, alt text on stack icons, and the location-page TBT investigation — real, but lower urgency than the five above.
